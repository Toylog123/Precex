
# 主编决定与修订路线图（Editorial Decision & Revision Roadmap）

> 依据：academic-paper-reviewer（full 模式）Phase 2 综合。五份独立评审：EIC 42、方法学 38、领域 50、交叉视角 46、魔鬼代言人 35。平均约 42/100。

## 编辑决定：**Major Revision（接近拒稿线）**

- 五位评审在以下三点完全一致（共识）：
  1. 主实验数字来自 ground-truth 泄漏版本且未披露 → 全部统计结论作废，必须按干净口径重算并披露（P0，五人均列）；
  2. "修复率 100%" 在有限深度 BMC + 弱 tb + 不改断言集的判据下缺乏信息量，不能作为能力卖点（P0，方法学/魔鬼代言人/交叉视角一致）；
  3. 论文贡献过载、叙事不聚焦；"证据表征消融"的结论在干净数据上反转（A 64.7% > C 59.8% > B 55.9%），必须重构叙事（P0/P1，五人一致）。
- 分歧点：EIC/领域认为"评测双卫生（数据+判据）"重构后有机会（50 分档）；魔鬼代言人认为必须接受"精度最优"叙事死亡的事实（35 分档）。主编裁决：**采纳"双卫生/可靠性"重构方向**——这是唯一既诚实又有领域区分度的路径。

## 修订路线图（可直接作为 revision 模式输入）

### R0（P0，阻塞，必须先做）：数据口径与披露
- [ ] 决策：口径 A（补跑 MiniMax M3 408 次干净，约 11 美元、小时级，保住跨模型叙事）或口径 B（DS 306 干净为主实验，MiniMax 旧数字全部删除）。**推荐 A**（成本可控且论文跨模型章节需要它；若账户/时间受限则选 B）。
- [ ] 无泄漏重跑已就绪：leakfix_0..7 共 306 条（已补全校验，A 64.7%、B 55.9%、C 59.8%、repair 100%、68 处翻转）。若选 B，直接以本数据集重写全部表格；若选 A，先跑 MiniMax 干净复跑再重写。
- [ ] 论文新增"数据卫生审计"小节：泄漏三来源（prompt 元数据 inject_line / evidence.json 全文 / buggy.v 头注释）→ 修复（strip_ground_truth + sanitize_design_text，行数不变）→ 干净重跑 → 68 处翻转 → 教训。
- [ ] 摘要、贡献、表 3/4/5、发现 1/2/6、结论：全部改按干净口径；删除或标注"MiniMax 旧数字待复跑"。

### R1（P0）：判据叙事重写
- [ ] "修复"改述为"BMC 回归通过（有限深度、golden-first 一致性）"，全篇统一；放弃"修复率 100%"作为卖点。
- [ ] 补充判据强度证据：关键样本加深深度（建议 2-4 倍）或 k-归纳覆盖率；若无法做到，明确承认"弱修复未被系统排除"并给出缓解（delta-debugging/T2 只约束不根除——论文已有，需显性化）。
- [ ] L2 91.7% 假阳性重论证：区分"门禁纯度代价"与"对可观测错误过度修复"，补充 L2 定位/修复明细。

### R2（P1）：统计方法补全
- [ ] McNemar 实现细节；4 对比较多重校正（Holm/Bonferroni）；效应量与 CI；seed 独立性论证；成本按干净运行重算。

### R3（P1）：贡献重构（收敛为三条）
- [ ] ① 开源反例驱动修复流水线 + 34 样本 L3 基准 + 充分性审计协议（变异/空泛/T2/delta-debugging）；
- [ ] ② 干净证据消融（探索性）：证据表征效应被模型与数据卫生强烈调节，A/B/C 相对排序模型依赖；
- [ ] ③ 评测双卫生方法论教训：数据泄漏与判据失效都会系统性反转结论（68 处翻转 + 78 个误判双案例）。
- [ ] 相关工作补 CEGAR/极小反例核心、semiformal、SEC；数据卫生对齐 SWE-bench 去污染实践。

### R4（P1/P2）：口径与术语
- [ ] "跨周期（L3）"给操作定义并承认教学级边界；目标期刊与语言定稿（中文期刊 or 英文 IEEE）；外部效度声明收紧。

### R5（P2，对齐 PreCex++ 路线）：未来工作段
- [ ] 把未来工作与系统升级路线（结构修复模板/PatchAssembler、动态轨迹切片/TraceAnalyzer、反馈闭环/cex_diff、多候选仲裁、顶层连接性检查、诊断驱动根因）统一，让论文的"下一步"与仓库实际进展一致（其中多项已完成，可在修改稿中引用）。
