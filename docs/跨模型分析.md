- 范围：A/B/C × 34 个 L3 样本 × seed 0 = 102 次调用（与 MiniMax 主实验 seed 0 对齐）
- 模型：deepseek-v4-flash（DeepSeek-V4-Flash-0731），temperature=0，OpenAI 兼容端点
- 判据：与 MiniMax 主实验完全一致（bmc 修复判据、loc_top1 行号判据）；MiniMax 基线用 corrected（BMC 重验 306/306）；对比口径为 seed0 严格配对（102 对）
- 执行：8 并行分片（run_experiments.py --provider deepseek），断点续跑 partial.jsonl，102/102 全部完成无失败

## 4. 关键发现与叙事影响

1. **B 的定位优势不跨模型成立**：MiniMax seed0 上 B 最强（64.7% vs A 41.2%，配对 McNemar p=0.0078 显著），但 DeepSeek 上 B=55.9% 被 C 反超（67.6%，B vs C p=0.125 不显著，n=34 小样本）。论文不能宣称"结构化证据普遍提升定位"，只能限定为"在 MiniMax 上 B 定位最优"。
2. **修复率跨模型一致（均为 100%，BMC 口径）**：DeepSeek 的"全修复"与 MiniMax 修正后口径相同，跨模型差异不体现在能否修复，而体现在定位与成本。
3. **成本下降约 9.4 倍**：同 102 对任务集 $3.19 → $0.34（严格配对口径）；deepseek-v4-flash 单价（$0.14/$0.28 per M）远低于 MiniMax（$0.60/$2.40），且 attempts=1（无重试）。全量 3 seeds 重跑预计约 $1。
4. **方法论教训**：跨模型对比必须先统一修复判据口径；若用旧 prove 判据（MiniMax 225/306）对比 DeepSeek（BMC 判据 102/102），会错误地得出"DeepSeek 修复率显著更高"。
4. **论文 implications**：
   - 主叙事改为"证据表征 × 模型交互效应"：B 优势是模型依赖的。
   - limitations 增补"跨模型鲁棒性"：单模型结论需限定。
   - 可将 DeepSeek 作为低成本复现/扩展通道（全量 3 seeds 仅 ~$1）。
