> 作者：Codex 自主推进｜日期：2026-08-05｜性质：真实实验，数据源 experiments/runs/experiments_results_ds.json（102 条）+ experiments_results_parallel.json（306 条）
> 目的：量化 B（结构化证据）定位优势是否跨模型成立，回答"单提供商威胁"。

## 1. 实验设置

- 范围：A/B/C × 34 个 L3 样本 × seed 0 = 102 次调用（与 MiniMax 主实验 seed 0 对齐）
- 模型：deepseek-v4-flash（DeepSeek-V4-Flash-0731），temperature=0，OpenAI 兼容端点
- 判据：与 MiniMax 主实验完全一致（bmc 修复判据、loc_top1 行号判据）
- 执行：8 并行分片（run_experiments.py --provider deepseek），断点续跑 partial.jsonl，102/102 全部完成无失败

## 4. 关键发现与叙事影响

1. **B 的定位优势不跨模型成立**：MiniMax 上 B 最强（61.8% vs A 46.1%），但 DeepSeek 上 B=55.9% 被 A/C 追平或反超（C 67.6%）。论文不能宣称"结构化证据普遍提升定位"，只能限定为"在 MiniMax 上 B 定位最优"。
2. **DeepSeek 修复率 100% 显著优于 MiniMax 73.5%**：可能源于 flash 模型输出更贴合 diff 格式/更少跑偏，或温度 0 更稳定。McNemar 显著。
3. **成本下降 28 倍**：$0.34 vs $9.61（相同任务集），deepseek-v4-flash 单价（$0.14/$0.28 per M）远低于 MiniMax（$0.60/$2.40），且 attempts=1（无重试）。
4. **论文 implications**：
   - 主叙事改为"证据表征 × 模型交互效应"：B 优势是模型依赖的。
   - limitations 增补"跨模型鲁棒性"：单模型结论需限定。
   - 可将 DeepSeek 作为低成本复现/扩展通道（全量 3 seeds 仅 ~$1）。
