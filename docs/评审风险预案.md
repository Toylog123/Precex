# PreCex 投稿前评审风险预案

> 作者：Toylog｜版本：v1.0（2026-08-05）｜性质：P2 评审演练产出——按方法/实验/可复现三个审稿人视角模拟攻击面，逐条给出回应预案。论文已按本清单完成对应修正。

## 一、方法审稿人视角

### R1. 为什么用 BMC 而非 prove/k-归纳作主判据？是否自圆其说？
- 攻击点：BMC 深度上界不保证完备性，可能放走更深缺陷。
- 回应：已实现 golden-first 规则（判据先在 golden 上验证，golden 在 prove 下 UNKNOWN 说明判据不可用）；BMC 对带门控时序断言的模块探测深度+2 并与 golden 交叉核对；充分性变异审计（88.5%/81.8% 被杀）与删除变异空泛性控制量化断言集捕获缺陷的能力。论文方法节与局限性均已声明 BMC 深度上界非完备性保证。
- 预案：若审稿人要求，可补一条 BMC 深度敏感性实验（depth 16→24 抽查）作为后续补充实验项。

### R2. 证据表征消融是否公平？D（因果图）是否真的「零 LLM 成本」？
- 回应：四种设置共用同一 prompt 家族、仅替换证据段（论文 tab:evidence 说明提取方式）；B/D 均为确定性提取（evidence.json/因果图），C 唯一引入一次 LLM 语义化调用；成本表按 token 记账，C 成本 4.17 美元显著高于 B/D，论文已如实报告。
- 预案：可在补充材料列出每个样本的 prompt 模板差异（experiments/configs/prompt_templates.py 已入库）。

### R3. 修复判据是否会被 LLM「学习/迎合」？
- 攻击点：LLM 可能生成能骗过 BMC 但语义错误的补丁。
- 回应：T2 确定性审计对 408/408 条修复检查接口/端口/参数变更、断言篡改、证据闭环一致性，均零失败；补丁最小化（均值 2.1 行/最大 6 行）+ loc_dev 中位数 0 佐证修复贴近注入点；golden 双重校验要求 golden 本身通过。论文局限性已声明「属性集之外的行为改变无法完全排除」。

## 二、实验审稿人视角

### R4. 跨模型结论是否站得住？只有 1 个 seed、1 个外部模型。
- 回应：跨模型用 seed0 严格配对（102 对）对比，报告了 McNemar 不一致对 0 与逐设置 p 值；明确结论是「定位优势模型依赖」而非「跨模型普遍」；论文声明多提供商多模型评测列未来工作。
- 预案：若被追问，可补 DeepSeek seed1/seed2（约 $1）验证趋势稳定性。

### R5. 错误类别与 L2 样本量太小（n=3/9/12/24）。
- 回应：论文已加小样本 caveat（如 D 在握手 41.7%，n=12 谨慎解读；L2 n=24 小样本）；错误类别难度排序（状态迁移/握手难、位宽截断/边沿易）在全部设置中稳定，是稳健发现。
- 预案：不主动扩展样本（会改变论文范围），保持现有谨慎表述。

### R6. 可解释性评分是否有效？ICC 的「一致性」不等于「正确性」。
- 回应：论文明确这是探索性结果，如实报告 LLM 代理评分局限，说明跨模型一致性仅在因果链维度可信，其余维度主观差异大需人工标定；已预留人工评分协议（P4）。
- 预案：不将可解释性作为主结论，仅作探索性小节。

### R7. 成本数字是估算而非平台账单。
- 回应：论文实验设置明确标注「单价为估算值而非平台账单」，并给出单价与公式（input×0.60/2.40 + output×0.24/1.0M）；账本 1519 条全部按同一公式核算，ratio=1.000 自洽。
- 预案：若审稿人质疑，提供 DeepSeek/MiniMax 官方定价链接作为附录。
