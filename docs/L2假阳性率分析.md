# L2 假阳性率分析报告（方案 A：24 样本双检 + 72 次 DeepSeek 评测）

> 作者：Codex 自主推进｜日期：2026-08-05｜性质：真实实验，数据源 samples/l2/（24 样本）+ experiments/runs/experiments_results_l2.json（72 条）
> 目的：量化"弱 tb 能抓但 formal 也失败"的伪 L3 比例（假阳性率口径），回答 L2/L3 纯度门禁的区分度。

## 1. L2 样本集（数据资产）

- 生成：scripts/bug_injector.py --level L2（弱 tb FAIL + formal fail 双检，verdict=L2_VALID）
- 数量：24 个正式样本（samples/l2/），分布：axi 5 / counter 4 / fifo 6 / fsm 4 / uart_rx 3 / uart_tx 2
- 错误类型覆盖：边界回绕 / 位宽截断 / 握手 / 复位 / 状态跳转 / FIFO 满空
- uart 类用参数化小 DIV（CLK_FREQ=400,BAUD=100）使 formal 在浅深度可及
- 双检全部通过：compile ✓ + 弱 tb FAIL ✓ + formal fail ✓（每样本 meta.json 有 L2_VALID 记录）
- 大量候选被筛掉（弱 tb 抓不到或 formal 不过），如实记录了失败变体——这是 L2 定义的自然筛选

## 2. 主实验（DeepSeek）

- 范围：24 样本 × A/B/C × seed 0 = 72 次调用
- 模型：deepseek-v4-flash，temperature=0，判据与 L3 主实验一致
- 完成：72/72（6 分片并行，partial.jsonl 断点续跑）
- 总成本：$0.289（平均 $0.004/次）

## 4. 假阳性率解读（关键）

1. **假阳性率 = 91.7%**：24 个 L2 样本全部满足"弱 tb FAIL + formal fail"（伪 L3 判据），系统把其中 91.7% 当 L3 修复到三通过（PASS）。即：**弱 tb 门禁对系统区分度有限——系统能修好绝大多数单周期错误**，L2 样本几乎全被系统当作 L3 处理。
2. **L3 基线 100% vs L2 91.7%**：差异 -8.3pp。系统对 L2（单周期可观测）修复率略低于 L3（跨周期不可观测），但差距不大——说明"弱 tb 能抓"不构成系统能力的显著分界。
3. **uart_tx 短板**：l2_uarttx_01（握手：起始位失效）、l2_uarttx_02（状态跳转：跳 STOP）修复率 0%。这两个错误在参数化小 DIV 下 LLM 无法定位/修复，是 L2 集里唯一全失败模块——论文 limitations 应报告。
4. **B 在 L2 上无显著定位优势**：loc_top1 B=50.0% vs A=45.8%（+4.2pp），远小于 L3 主实验的差距；与跨模型发现一致：证据表征优势是任务/模型依赖的。

## 5. 论文 implications

- 可加入 L2 对照组：修复率 91.7% vs L3 100%，量化"纯度门禁代价"。
- limitations 增补：L2 假阳性率 91.7% 说明弱 tb 筛选不构成系统能力分界；uart_tx 握手/状态类 L2 是系统短板。
- 成本可忽略（$0.29），L2 资产可复用做扩展。
