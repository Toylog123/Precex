
# 验证完备性决策（Phase 3 门禁判定）

> 日期：2026-08-07 ｜ 依据：experiments/runs/kinduction_feasibility.json（34 golden × sby prove 模式，timeout 600s）

## 扫描结果

| 结果 | 数量 | 说明 |
|---|---|---|
| PROVE（k-归纳收敛） | 25 | 归纳证明成功 |
| PASS（基例过、归纳不收敛） | 9 | BMC 深度内安全但断言非归纳性质 |
| FAIL / TIMEOUT / ERROR | 0 / 0 / 0 | 无 |

**收敛率 = 25/34 = 73.5%**（门禁 ≥ 80% 未达标）

## 不收敛的 9 个样本

全部集中在门控时序断言模块（与论文 §VI 已知结论一致）：
- axi_lite_slave（s17/s25/s27/s28/s33/s34 等）
- uart_rx（s18/s26 等）
- uart_tx 握手类（s16）

这类断言的验证条件是"上一周期状态 + 本周期事件"的组合，归纳步需要更强的中间不变式，smtbmc 在 depth 范围内无法自动构造。

## 门禁判定

- [x] 收敛率 < 80% → **k-归纳/CEGAR 判据升级延后**
- [x] 不动投稿版 v1（BMC 口径冻结）
- [x] 出路：断言增强（变异驱动的断言补全）作为 v2 独立线；论文如实报告"当前断言集下 k-归纳收敛率 73.5%，axi/uart 门控断言是主要瓶颈"

## 对论文的支撑

该负结果反而强化论文的判据卫生贡献：
1. 证明 BMC 有限深度口径不是"偷懒降级"，而是当前断言集下唯一收敛的验证判据；
2. golden 本身 73.5% 不满足归纳，修复后设计的 prove 失败不能被解释为"修复没修好"（判据翻案的直接证据）；
3. 与 §V-D 判据翻案审计（prove 误判 78 个正确修复）互相印证。
