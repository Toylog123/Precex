**核心事实（已验证，非推断）**：
1. **主实验数字已作废**：8 月 5 日 skill 审计确认三处 ground-truth 泄漏（prompt 元数据 inject_line；B 设置 evidence.json 全文含 inject_line/inject_desc；buggy.v 头注释含缺陷描述与行号）。论文摘要/贡献/表 3/4/5/结论仍引用泄漏版数字（B 61.8% 等）。

3. **判据弱度问题**：有限深度 BMC + 弱 tb + 不改断言集的三通过判据不能支撑"修复"承诺；100% 通过率主要是判据的度量。
4. **设计亮点仍在**：开源端到端流水线、充分性审计（变异 88.5/81.8%、删除变异空泛性控制、T2、delta-debugging）、golden-first 判据原则、数据卫生修复工具（strip_ground_truth/sanitize_design_text）。

**系统能力现状**（按今晚已完成工作）：
- 证据表征消融：干净结论 A>C>B（与旧结论相反）→ 定位结论必须重写为"模型依赖 + 卫生依赖"。
- 修复判据：BMC + golden-first；深度敏感性抽查 5 个代表样本通过，但非系统性。
- 反馈闭环：历史修复记忆 + cex_diff 差分诊断已实现（e2e 6/6，含 2 个真实多轮收敛 s38/s40）。

## 二、论文重构方案（R0-R5，对应主编路线图）

### R0 数据口径（阻塞项，先做）
- **推荐口径 A**：补跑 MiniMax M3 408 次干净（约 11 美元、小时级）。理由：论文跨模型章节（表 5/发现 6）需要两模型配对；DS 306 干净已就绪可作为对照组。
- 若账户/时间受限，选口径 B：以 DS 306 干净为主实验，删除全部 MiniMax 旧数字，跨模型章节改为"与旧泄漏版对比"（本身就是卫生教训案例）。

### R1 判据叙事（P0）
- 全篇把"修复"改述为"BMC 回归通过（有限深度、golden-first 一致性）"。
- 补判据强度证据：关键样本加深深度（2-4 倍）或 k-归纳覆盖率；做不到就显性承认弱修复边界。
- L2 91.7% 假阳性重论证（门禁代价 vs 过度修复），补 L2 定位/修复明细。

### R2 统计（P1）
- McNemar 细节、多重比较校正（Holm）、效应量/CI、seed 独立性论证；成本按干净运行重算。

### R3 贡献重构（P1，收敛为三条）
1. 开源反例驱动修复流水线 + 34 样本 L3 基准 + 充分性审计协议；
2. 干净证据消融（探索性）：证据表征效应被模型与数据卫生强烈调节（A>C>B on DS）；
3. 评测双卫生方法论教训：数据泄漏 + 判据失效都会系统性反转结论（68 翻转 + 78 误判双案例）。

### R4 口径与术语（P1/P2）
