# PreCex：反例驱动的综合前 RTL 缺陷定位与修复智能体（难度评估）

> 项目名：PreCex（Pre-synthesis + Counterexample）

> 作者：Toylog
> 版本：v1.0（2026-08-03）
> 功能概述：对《项目方案.md》v1.4 与《详细方案说明.md》的逐项难度评估：组件级、里程碑级、任务级三张难度表 + 关键难点 TOP 清单 + 3 个月可行性论证。

---

## 1. 评估体系

**难度等级**：低（L1）/ 中（M2）/ 高（H3）/ 极高（VH4）

**评估维度**：
| 维度 | 含义 |
| --- | --- |
| 技术难度 T | 实现本身的复杂度（算法、工具、工程） |
| 工作量 W | 单人 + 智能体协助下的人天估算 |
| 不确定性 U | 结果不确定性对论文成败的影响 |
| 依赖 D | 外部依赖风险（工具/API/方法学） |

## 2. 逐组件难度评估

| 组件 | T | W | U | D | 总体 | 主要理由 |
| --- | --- | --- | --- | --- | --- | --- |
| EvidenceEngine | 低 | 3–5 | 低 | 低 | **低** | 正则+规则可覆盖 80% 格式；X 态归一化方案明确 |
| **CexSemantizer** | **中高** | 8–12 | **高** | 中 | **高** | 核心创新点：VCD 解析+周期切分+故障锥，解析工作量最大；**C vs B 增益是全局最大不确定性** |
| LocalRepairer | 中 | 5–8 | 中 | 中 | 中 | prompt 工程 + diff 校验成熟；但修复成功率依赖 M3 能力 |
| Verifier | 中高 | 8–12 | 中 | 中 | **中高** | sby 配置/断言子集/mutation/vacuity 四件事；断言子集兼容待 Gate-1 实测；vacuity 无现成工具需自研 |
| Controller | 低 | 3–5 | 低 | 低 | 低 | 调度规则简单；消融负结果也合法（CVDP 已背书） |
| BugBench-PS | 中 | **10–15** | 中 | 低 | **中高** | **工作量最大**（6 模块 × 5–7 注入 + 逐样本校验）；弱 tb 强度把控是隐性难点 |

**结论**：技术实现难度整体**中**；科研不确定性集中在 CexSemantizer（U=高），工作量集中在 BugBench-PS（10–15 人天）。

## 3. 逐里程碑难度评估（时间压力维度）

| 周次 | 里程碑 | 时间压力 | 风险点 | 缓解 |
| --- | --- | --- | --- | --- |
| W1 | M0 | 中 | 断言子集若大量不兼容，需快速收敛 | Gate-1 集中实测；先定 5 条安全子集保底 |
| W2–3 | M0.5 | **高** | 3 例 × 3 设置的预研结果决定主叙事 | 预研脚本先行写好；并行启动注入器 |
| W4–7 | M1+M2 | **高** | 工作量最大阶段；样本稳定性 | 注入器自动化 + 每样本自动校验；解析器与数据集并行 |
| W7–9 | M3+M4 | **高** | 批量跑依赖数据集与解析器质量 | 评测管线一键化；跑批无人值守 |
| W9–10 | M5 | 低–中 | 消融项，无增益也合法 | 复跑脚本复用 |
| W11–13 | M6 | **高** | 论文依赖全部结果就绪 | 写作贯穿全程，非 W11 才动笔 |

**结论**：W2–W7 是连续高压段（预研→数据→解析器），是 13 周的咽喉。

## 4. 逐任务难度评估

| 任务 | 难度 | 说明 |
| --- | --- | --- |
| VCD 解析 | 中 | pyvcd 可用，但反例 VCD 可能含 `x/z`，需清洗 |
| 周期切分 | 低–中 | 算法明确（以 clk 上升沿切分），边界情况（复位周期）需处理 |
| 故障锥静态提取 | 中 | 用源码静态依赖近似；不做 SAT，精度够用 |
| 波形渲染（T1） | 低 | gtkwave 批处理/自绘 SVG；**但 VLM 提取效果不确定性高（U=高）** |
| LLM 集成（M3 SDK） | 低 | OpenAI 兼容，成熟 |
| prompt 工程（A/B/C/D 对照） | 中 | 模板族设计 + 迭代调优；严格对照是论文可信度关键 |
| sby bmc/k-induction 配置 | 中 | 参数（深度、引擎）需对 6 模块逐一定标 |
| mutation 注入器 | 中 | 6 类注入规则明确；注入后自动校验 |
| vacuity 近似 | **中高** | 无现成工具；用"断言翻转 mutation"近似，**论文中需谨慎表述为近似方法** |
| 数据集校验管线 | 中高 | 自动化 + 人工抽查结合；弱 tb 强度把控 |
| 统计与结果表 | 低–中 | n≥20 + McNemar 检验，标准流程 |
| 论文写作 | 中高 | 对比 FVDebug/GROVE 的压力大；需差异化论证充分 |

## 6. 总体难度结论与 3 个月可行性论证

### 6.1 总体评级
| 维度 | 评级 | 结论 |
| --- | --- | --- |
| 技术实现难度 | **中** | 无原理性未知；最大工作量在解析器与数据集，均为"确定的工程" |
| 科研不确定性 | **高** | 集中在 C vs B（Gate-0）；已通过预研前移 + 双叙事预案对冲 |
| 时间压力 | **高** | 13 周紧；靠并行（W4–7 双线）+ 自动化（注入器/评测一键化）化解 |
| 外部依赖 | **低–中** | 工具链已装；M3 API 已确认；无算力瓶颈 |

### 6.2 可行性论证（为什么 3 个月可做）
1. **无原理性未知**：所有组件都有成熟方法或文献先例（解析/VCD/sby/mutation 均有现成工具与论文支撑）；
2. **不确定性已前移**：两个最不确定的点（C vs B、断言子集）都在 W3 前验证，返工成本最低化；
3. **最大工作量自动化**：数据集构建与批量评测是纯"可脚本化"工作，智能体可无人值守执行；
4. **降级路径清晰**：Gate-0 不通过 → 切稳妥叙事，不返工、不推倒。

### 6.3 一句话结论
**方案整体难度为中高，可做**：技术上是"工程量大但无原理风险"，科研上是"一个高风险变量（C vs B）已用 Gate-0 前移控制"——3 个月交付论文初稿的把握成立，前提是严格执行 W1→W3 的两个 Gate。
