## 论文主题

综合前阶段，跨周期行为缺陷（弱测试平台仿真通过而形式验证失败）是最难定位与修复的 RTL 缺陷之一。本文提出 PreCex——一个完全开源、反例驱动的 RTL 缺陷定位与修复流水线，基于 iverilog/Yosys/SymbiYosys/Z3 与大语言模型（LLM），将失败的形式化反例转换为结构化证据，定位缺陷区域并生成最小补丁，在带 golden-first 规则的有界模型检验（BMC）判据下重新验证。

## 主要贡献

1. **开源反例驱动修复流水线**：端到端实现完全可复现，配套 34 样本 L3 数据集（6 模块 × 7 错误类型），含 golden 双重校验与充分性审计。
2. **证据表征受控消融**：在统一 BMC 判据下比较四种证据表征（原始日志、结构化证据、反例语义化、FVDebug 式因果图）共 408 次干净（无泄漏）真实 LLM 修复运行，BMC 回归通过率均达 100%；定位精度 A 64.7% > C 59.8% > D 56.9% > B 55.9%（配对检验均不显著），因果图（D）成本最低（$0.37 vs A $0.60）；深时序子集（60/60，修复率 100%）上排序反转为 C 75.0% > A 66.7% > D 58.3% > B 41.7%。
3. **验证充分性闭环**：强变异 88.5%、常量变异 81.8% 被杀，空泛性控制通过，独立 T2 审计 306/306 + 102/102 全部通过（接口变更、断言篡改均为零）。
4. **判据翻案的方法论教训**：发现原 prove/k-归纳判据在门控时序断言上误判 78 个正确修复，确立 golden-first 规则，为自动修复评测提供可复用方法学。
5. **数据卫生方法论教训**：初版实验三处 ground-truth 泄漏导致“B 显著最优”伪结论，剥离后 68 处定位翻转、结论反转——数据卫生（ground-truth 隔离）是自动修复评测可靠性的前提。

## 与已有工作的区别

与 FVDebug（2025）、GROVE（2025）等反例理解系统相比，PreCex 同时具备四点能力：完全开源、面向跨周期缺陷的系统性研究、严格的验证充分性闭环、证据表征的受控消融——这三项差异均有受控实验佐证。

## 数据与可复现性承诺

全部实验基于开源工具链（iverilog 12.0 / verilator 5.020 / yosys 0.33 / SymbiYosys / Python 3.12），修复成功由编译、弱测试平台回归与形式 BMC 裁决，从不依赖 LLM 自述。全部结果文件（干净口径：主实验 408 次、L2 72 次（BMC 通过率 91.7%）、深时序子集 60 次、token 账本 2578 条）已入库并通过复现审计（audit_paper_numbers 55 项全 PASS），见仓库 REPRO.md。
