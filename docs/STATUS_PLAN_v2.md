### C 定位下降分析（已归档：MM->DS 切换）

MM 版摘要 3K-20K 字符含推理链——冗余但含定位线索（C=59.8%）。
DS 版 300-500 字符更精简，但定位信息密度下降（C=43.2%）。
最终论文如实报告 DS 摘要版 43.2%（95/102），A vs C 统计显著（Holm p=0.0024）。
