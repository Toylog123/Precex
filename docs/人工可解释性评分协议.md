# PreCex 人工可解释性评分协议（P4）

> 作者：Toylog｜版本：v1.0（2026-08-05）｜性质：论文「证据可解释性的多模型评估」小节的人工评分配套材料。
> 背景：论文已用 2 个 LLM（DeepSeek v4-flash + MiniMax M3）对 10 个样本的 C/D 证据做 5 维 Likert 评分并报告 ICC(2,1)（C 因果性 0.656、可操作性 0.774；其余维度 ≈0）。LLM 代理评分存在主观性局限，论文如实声明，需真人评分者校准。
> 决策（2026-08-05）：用户确认无真人评分者，论文以多 LLM 交叉评分作为探索性结果投稿；本协议保留备用（若未来补充真人评分，按本协议执行）。

## 一、评分对象

- 样本：s08、s09、s11、s14、s15、s17、s21、s26、s28、s31（10 个）
- 证据类型：C（反例语义化：周期事件+状态轨迹+故障锥+自然语言摘要，window=8）；D（FVDebug 式因果图：失败断言+故障锥+全周期状态轨迹+触发条件）
- 每个样本需分别对 C 和 D 评分 → 共 20 个评分单元
- 材料位置：samples/bugs/<样本>/（buggy.v 设计文件、semantics.json、evidence.json、cex.log）

## 二、评分维度（5 级 Likert，1-5 分）

1. **完整性（completeness）**：证据是否覆盖定位所需的全部关键信息（失败信号、触发条件、周期轨迹、相关代码位置）？
   - 5=完整覆盖且无冗余；4=基本完整，缺少量次要信息；3=覆盖核心但缺关键细节；2=明显缺失关键信息；1=几乎无法支撑定位。
2. **可读性（readability）**：证据结构是否清晰、易于人类快速理解？
   - 5=清晰简洁，一眼可读；4=较清晰，偶有晦涩；3=可读但需费力；2=结构混乱；1=几乎不可读。
3. **因果性（causality）**：证据是否明确呈现「缺陷 → 失败断言」的因果链？
   - 5=因果链完整清晰；4=因果链基本完整；3=有因果线索但不完整；2=因果线索零散；1=无因果信息。
4. **可操作性（actionability）**：证据能否直接指导定位到具体代码行/信号？
   - 5=可直接定位到候选行；4=定位方向明确；3=有参考价值但需进一步排查；2=方向模糊；1=无定位指引。
5. **可信度（trustworthiness）**：证据来源与内容是否可靠、无歧义、无冲突？
   - 5=完全可信；4=基本可信；3=部分存疑；2=多处存疑；1=不可信。

## 三、评分者指引

- 每位评分者独立评分，不得查看 LLM 评分结果，不得互相讨论（保证 ICC 有效性）。
- 建议 2-3 名熟悉 RTL 验证的评分者（可含作者，但需独立完成）。
- 评分前先阅读样本的 buggy.v（含缺陷）与失败断言，再阅读 C/D 证据材料。
- 对每个评分单元给出 5 个维度的整数分（1-5），并可选给出「基于证据能定位到的 Top-1 行号」作为行为代理。
- 单个样本建议 10-15 分钟，总时长约 3-4 小时/评分者。

## 七、评分者角色重叠披露（2026-08-06 追加）

> 用户质疑"DS 既是选手又是裁判"。核查属实，且比预想更严重：**两位评分者都与流水线有角色重叠**。

### 角色矩阵（已查证）

| 对象 | 生成者 | 评分者 | 重叠 |
| --- | --- | --- | --- |
| C 证据（semantics.json） | MiniMax M3（CexSemantizer 真实模式，summary_meta.mode=real 可查证） | DeepSeek v4-flash + MiniMax M3 | MiniMax 评分者=生成者 |
| D 证据（evidence.json） | 确定性证据引擎（EvidenceEngine） | DeepSeek v4-flash + MiniMax M3 | DeepSeek 评分者=主实验修复模型 |
| 主实验修复（loc_top1/修复率） | DeepSeek v4-flash | 无 LLM 评分（BMC 确定性判据） | 无（核心指标不受影响） |

### 结论与披露口径

- 论文「证据可解释性的多模型评估」小节已如实披露角色矩阵，将 ICC 解读限定为"流水线内双 LLM 交叉一致性"，并明确不支撑"某表征客观更可解释"的主张；行为代理（loc_top1）为客观指标，不受影响。
- 核心结论（定位/修复/BMC）全部为确定性判据，无 LLM 裁判，**不受"选手兼裁判"影响**。
- 该小节现有结论本身是"两模型大多不一致"（C 五维仅因果性/可操作性 ICC 中等，D 五维全 ≈0），未因重叠而自我拔高；披露后口径更严谨。

### 后续强化（可选，需用户提供第三方 key）

- 引入与流水线**无任何角色重叠**的第三方评分模型（如通义千问/智谱/Claude/GPT 系列），约 40 次调用 ≈ $0.1：
