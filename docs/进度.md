### 2026-08-04｜纠错：axi 断言 killed=0% 实锤结论撤回——原因为布尔变异未生效 + 比较变异算子弱化（实测 100% killed）
- 纠错背景：此前记录"6 个 axi 样本 killed=0%（断言冗余/充分性不足）"，经复核为**方法学 bug 造成的假象**，结论撤回
- 根因（两个独立 bug）：
  - **布尔变异未生效**：mutate_line 用 `line.replace('assert(', ...)` 替换，但 golden.v 风格为 `assert (`（带空格），
    replace 匹配不到，m0-m4/m10-m14 的 golden.v 与原文件逐字节相同（IDENTICAL），10 个"布尔变异"实际没变异
  - **比较变异算子弱化**：OP_REPLACEMENT 对 == 随机选 !=/>=/<=，多数跑成 >=/<=（被原式蕴含的弱化变异），
    golden 下 RDATA==rd_exp 恒真时 >= 天然 PASS，killed=0% 是算子缺陷而非断言冗余
- 修复与实测（scripts/verify_sufficiency.py）：
  - mutate_line 布尔分支改用 `re.sub('assert\s*\(\s*!', ...)`，兼容 `assert (` 带空格；`assert(x)->assert(!x)` 同理
    替换（此前用 replace 精确匹配 `assert(` 无空格风格，对带空格风格失效）
  - 新增 --strong：比较变异强制取反语义（==<->!=、>=<->< 等），避免弱化变异虚报；--depth 可覆盖 BMC depth
  - 6 个 axi 样本（s17/s25/s27/s28/s33/s34）×15 变异 = 90 变异，--strong --depth 64 并行 8 任务实测：
    **90/90 killed（100%）**，全部 DONE (FAIL, rc=2)，文件 experiments/runs/sufficiency_axi_strong_d64.json
  - 抽查 s25 m0：真实 Assert failed（golden.v:219-220）step 4，depth 64 足够（非超时/非误报）
- 结论修正（论文断言质量章节）：
  - **axi 断言充分性良好**（取反即被击杀），与主实验 6 个 axi 样本修复率 0% 之间**不存在**"断言无法捕获缺陷"的因果链；
    修复率低需另找原因（如修复动作/证据质量），不能归因于断言冗余
  - 全量 43% killed 需复核：此前的 323 变异中布尔变异可能大量未生效 + 比较变异偏弱化，真实 killed 率需重跑 --strong 后定论
- 全量权威数据（已重跑完成）：
  - **34 样本 400 个强变异（--strong --depth 16，8 并发，118s）→ 354 killed = 88.5%**
    文件 experiments/runs/sufficiency_all_strong_d16.json
  - 5 个并发 ERROR（s21/s22/s37）串行重跑全部确认，1 个为真 PASS（s37 line176 state_d==S_STOP 取反）
  - 分模块：axi_lite_slave（s17/s25/s27/s28/s33/s34）**15/15×6 = 100%**；fifo（s04-06/s12-14/s19-23/s29）大多 100%；
    uart_rx（s18/s26）最低 50%——门控前提（A1/A2/A3 状态+计数中点采样、A4 case 分支跳转）使断言取反不可达（真冗余），
    depth 64 抽查仍 PASS，排除深度不足
  - 此前"43% killed"是弱化+未生效变异造成的低估，真实 88.5%
- 遗留：主实验 6 个 axi 样本修复率 0% 的根因仍待查（不再是断言充分性问题），后续从修复动作/证据质量入手
