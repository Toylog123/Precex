### 2026-08-03｜W1 M0 工具链验证（完成）✅ Gate-1 通过
- 完成项：
  - **工具链版本验证（WSL）**：iverilog 12.0 / verilator 5.020 / yosys 0.33 (git 2584903a060) / sby（Yosys 0.33 捆绑）/ python3 3.12.3
  - **断言子集双工具实测**：`smoke/diag_assert_v3.sh` 15 条用例 × 3 通道（iverilog / yosys -formal / yosys 默认）实测矩阵 → 收敛 **5 条安全子集**（immediate assert、if 条件门控 assert、寄存器打拍跨周期、immediate assume、initial 初始化寄存器）
  - **方案 6.4 候选表修正**：`assert property` 全系（含无时钟/@(posedge clk)/disable iff）、`|->`、`##1`、`$past/$rose`（concurrent 语境）**双工具实测均不可用**→ 删除；新增打拍模式替代；无时钟 `assert property` 仅 yosys 可用列为扩展
  - **smoke 冒烟三步**（L3 原型 counter 2→0 bug）：① 弱 tb 过（`PASS: weak testbench passed (buggy design)`）；② formal 败（sby smtbmc+z3，`Assert failed ... step 4`，DONE FAIL rc=2，生成反例波形）；③ golden 对照（2→3 正确版 bmc PASS 且 **k-induction 可证**，断言非空洞、能区分好坏）
  - **harness/evaluator.py 骨架**：compile→sim→formal 三通过判定 + CLI + 内置自检（对 smoke 样例 verdict=FAIL，正确判定 bug 存在）
  - **rtl/ 6 模块黄金基线**：fifo_sync/uart_tx/uart_rx/axi_lite_slave/fsm_ctrl/counter_alu，每模块含设计+强断言（安全子集）+弱 tb+README，全部 iverilog 编译 0 error + vvp 仿真 PASS + yosys 读取 0 ERROR
- 关键决策：
  - sby 引擎链定案：**smtbmc + z3**（`pip3 install --user z3-solver`，wrapper `smoke/yosys-smtbmc-z3.sh` 注入 `SMTBMC` 与 PATH）；弃用 `abc bmc3`（sby 0.33 + 新版 yosys-abc 的 cex ywa 格式不兼容，`KeyError: 'asserts'`）
  - .sby 一律显式 `read -sv -formal`（实测 sby 默认 `read -sv` 不自动附加 `-formal`）
  - `$fatal` 首个参数必须为数字 `$fatal(1,"msg")`（iverilog 12 强制）；**iverilog 12 `always @(*)` 时间 0 求值缺陷**（带初始化值输入组合块输出 X）→ 组合逻辑一律用 `assign` 实现
- 风险与变化：
  - 断言子集实际比方案 6.4 预估**更保守**（iverilog 12 不支持 `assert property` 任何形式）→ 方案风险 1 缓解，L3 跨周期性质改由打拍实现（等价语义）
- 验证证据：
  - `smoke/断言子集收敛.md`：完整 15 条×3 通道兼容矩阵 + 安全子集写法 + 冒烟证据 + 方案 6.4 修正对照
