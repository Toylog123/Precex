## 关键规则

1. **runs/ 与所有仿真产物（*.vcd/*.log/sby_*）不入库**（见 .gitignore），保证仓库轻量与可复现（复现靠脚本重建）；
2. **样本唯一标识 sNN**：s01 起连续编号，index 记录模块×错误类型矩阵；
3. **prompt 模板版本化**：experiments/configs 下按模板族管理，A/B/C/D 严格同模板族仅换证据段；
4. **token 记账强制**：所有 LLM 调用经 harness/llm_client.py，自动记录 in/out token 与费用；
5. **工具版本锁定**：scripts/setup_env.sh 与 manifest 记录 iverilog/yosys/sby 版本。
